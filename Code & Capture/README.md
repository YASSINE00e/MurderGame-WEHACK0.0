# CODE & CAPTURE: ZERO DAY

## Overview

**CODE & CAPTURE: ZERO DAY** is an immersive cybersecurity-themed murder mystery game. Players must navigate through a world of hacking, digital forensics, and network analysis to uncover the truth behind a critical security breach and capture the culprit.

## Game Concept

You are a digital detective tasked with solving a complex murder mystery in the digital age. The investigation requires you to:

- Analyze digital evidence
- Communicate with suspects via encrypted messenger
- Access restricted police databases
- Navigate server administration systems
- Decode network traffic using network analysis tools
- Uncover leaked source code
- Decrypt terminal commands
- Piece together clues from an evidence board
- Reach the ultimate truth

## Features

- **Hacker Aesthetic**: Full-featured terminal-style interface with green monospace typography and authentic CRT effects
- **Multiple Investigation Tools**: Access to various digital systems and databases
- **Evidence Board**: Collect and organize clues to piece together the mystery
- **Messenger System**: Communicate with key suspects and gather information
- **Network Analysis**: Use Wireshark-inspired tools to analyze digital traffic
- **Police Database**: Access critical case information and suspect profiles
- **Server Admin Panel**: Navigate through system administration interfaces
- **Terminal Interface**: Execute commands and explore the filesystem
- **Interactive Solution**: Dynamic reveal of the truth behind the crime

## How to Play

1. **Start the Investigation**: Open `index.html` in your web browser
2. **Gather Evidence**: Visit the evidence board and other investigation tools to collect clues
3. **Interview Suspects**: Use the messenger system to question key suspects
4. **Analyze Data**: Use terminal and network analysis tools to uncover hidden information
5. **Connect the Dots**: Cross-reference information from multiple sources
6. **Reveal the Truth**: When you've gathered sufficient evidence, proceed to the solution page

## Technical Stack

- **HTML5**: Semantic markup and page structure
- **CSS3**: Advanced styling with animations, gradients, and terminal effects
- **JavaScript**: Interactive gameplay mechanics and logic
- **Responsive Design**: Playable on desktop and tablet devices

## Getting Started

1. Clone or download this repository
2. Open `index.html` in a modern web browser (Chrome, Firefox, Safari, or Edge)
3. No server setup required - game runs entirely client-side
4. No installation or dependencies needed

## Styling & Theme

- **Color Scheme**: Neon green (#00ff41) on black background
- **Typography**: Share Tech Mono monospace font for authentic terminal feel
