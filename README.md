# Murder Games

This repository contains a cybersecurity-themed murder mystery game with two variants:

- [WeHack0.0](WeHack0.0) - the original investigation game
- [Code & Capture](Code%20%26%20Capture) - a companion/alternate presentation of the same mystery experience

Each folder is a self-contained HTML/CSS/JavaScript game. Open the main `index.html` file inside the folder you want to play.

## Project Structure

- `WeHack0.0/` - game pages, solution page, and its project README
- `Code & Capture/` - game pages, solution page, and its project README

## How to Run

1. Open the repository folder in VS Code or File Explorer.
2. Choose a game folder.
3. Open that folder's `index.html` in a browser.
4. Play entirely client-side with no install or backend required.

## Notes

- The game is designed to work offline once the files are available locally.
- For gameplay details, clues, and file-specific notes, see the README inside each game folder.
- If you are sharing the project with others, start them at the folder-level `index.html` entry point rather than this top-level README.
